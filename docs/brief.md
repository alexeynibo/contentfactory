# ContentFactory — бриф

Источник: конспект обсуждения сервиса (прислан 2026-10-12).
Ниже всё взято из конспекта. Мои выводы для интерфейса собраны в разделе 7, а неясные места — в разделе 8.

---

## 1. Суть в одном абзаце
B2B-продукт («комбайн»), который закрывает типовые задачи бизнеса по фирменному стилю и контенту: картинки, сторис, презентации, видео, сайт, стратегия.
Пользователь рассказывает о компании, сервис вычленяет из рассказа факты и дальше работает с опорой на них.
Короткая формула: **упрощённый Claude Code + Higgsfield + Lovable + агенты в одном окне.**

## 2. Главный принцип: harness, а не агрегатор
| | Агрегатор | Harness (наш подход) |
|---|---|---|
| Что это | Проводник к нейросетям по подписке (OpenRouter, Krea) | Обвязка над нейросетью |
| Что делает | Даёт доступ, дальше пользователь сам | Читает запрос, переводит его, добавляет бренд и стиль, сам оценивает результат |
| Для кого | Для тех, кто уже знает, что ему нужно | Для бизнеса, который не знает, как правильно ставить задачу |
| Где ценность | В доступе | В цепочке промптов и алгоритме: какую нейросеть и когда вызывать |

**Ценность растёт вместе с контекстом.** Файлы, финансовая отчётность и история общения собираются в единый контекст компании.

## 3. Архитектура продукта
- **Чат — основа.** Поверх него открываются **артефакты**: админка сайта, галерея картинок, редактор презентации и т.д. Схема экрана: «чат + артефакт».
- **Агенты под типовые задачи:**
  - контент-стратегия;
  - посты;
  - видео и раскадровка;
  - дашборды по Яндекс.Директ / Метрике;
  - разбор резюме;
  - тендеры и коммерческие предложения.
- Агенты подключаются по API/MCP. **Нейросети встроены в продукт.** Пользователь платит нам и не приносит свои подписки вроде Claude Code.
- **Человечность и подсказки** — отдельная ценность. Вместо пустой строки ввода сервис сам предлагает действия:
  - «Помнишь, вчера презентацию не доделал? Давай доделаем»;
  - «3 дня не было постов — давай сгенерируем».

  Такие подсказки помогают человеку освоиться в новом инструменте.
- **Референсы:** SnapBuild (Чулаков), Open Design, Maker / TryMaker.

## 4. Два продукта
1. **Maker** — для маркетологов: картинки, креативы, соцсети, чтобы вести клиентов.
   Сомнение маркетолога: без контент-завода и стратегии сервис «сам не полетит».
2. **B2B-комбайн** — более широкий и универсальный. Маркетолог в нём — лишь один из агентов.
   - Вход через брендинг: стратегия, логотип, ЦА. Затем расширение на остальные задачи.
   - Позиционирование: «замена маркетолога» / «виртуальные сотрудники», вплоть до HR-агентов.

## 5. Монетизация и партнёрство
- Своими силами не вытянуть, нужен партнёр с B2B-базой.
- Идеальный партнёр — банк, который выставит продукт на свою витрину.
- Банку это будет интересно только при реальной пользе для бизнеса, то есть при сильном harness.

## 6. Конкурс Точка Банка
- **Подача — 16-го.**
- План: неделя на концепт, +3 дня на дизайн по концепту, +неделя на вайбкодинг (быструю сборку с помощью ИИ).
- Цель — попасть в акселератор и привлечь инвестиции.
- Подаём оба проекта: Maker и B2B-комбайн.
- **Роли:**
  - **Лёша** — концептуальное видение, идея и визуал. Упор на соцсети и креативы: запрос на них есть, а сайты бизнесу часто не нужны.
  - **Катя** — Maker и визуальная часть.

## 7. Что это значит для интерфейса (мои выводы)
- Основной экран — **чат слева + рабочая область артефакта справа** (или похожая раскладка).
- Нужен список **агентов** как «виртуальных сотрудников»: их можно выбрать, подключить и посмотреть, кто чем занят.
- Нужно место для **контекста компании**: факты о бизнесе, бренд, загруженные файлы. Это видимое «мясо» harness, которое отличает нас от агрегатора.
- Стартовый экран — **не пустая строка ввода**, а персональные подсказки и незавершённые задачи.
- Приоритет визуала — **соцсети и креативы**: галерея картинок, сторис, посты.
