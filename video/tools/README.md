# Как пересобрать демо-видео

Инструменты, которыми собрано `video/contentfactory-demo.mp4`. Всё встроено в macOS и Chrome — ничего устанавливать не нужно.

| Файл | Что делает |
|---|---|
| `director.html` | Режиссёрская страница: открывает экран, выставляет состояния сцены (вкладка, этап, положение ползунка), прокрутку и сообщает область наезда камеры, точки и время для курсора |
| `scenes.py` | Список сцен: подпись в кадре, движение камеры и **текст диктора** — править здесь |
| `capture.py` | Снимает каждое состояние сцены и кадры прокрутки через Chrome (2880×1800) и озвучивает текст: ElevenLabs (Andrey), Yandex SpeechKit (Алёна) или голос macOS Milena |
| `render.swift` | Склейка: наезды камеры, курсор с кликами и перетаскиванием, смена состояний, прокрутка, наплывы, подписи, голос → MP4 |
| `probe.swift` | Проверка готового видео: длительность, дорожки, кадры на нужных секундах |

Рабочие файлы (кадры, звук, профиль Chrome) складываются в `build/` — она не попадает в git.

## Шаги

Проще всего попросить Claude: «пересобери демо-видео». Вручную:

1. **Запустить сайт** на `http://localhost:8080` (сервер `contentfactory` из `.claude/launch.json`) и положить `director.html` в папку `_video/` раздаваемой копии сайта — так, чтобы он открывался по адресу `http://localhost:8080/_video/director.html?s=home`.
2. **Снять кадры и озвучить:**
   ```bash
   CF_TTS=yandex python3 -I video/tools/capture.py
   ```
   Голос Алёна (Yandex SpeechKit), ключ берётся из `credentials.md`. `CF_TTS=elevenlabs` — клон Andrey в ElevenLabs (выразительность `CF_EL_STYLE`, стабильность `CF_EL_STABILITY`). Без `CF_TTS` — голос macOS Milena. `CF_REUSE_AUDIO=1` — переснять только кадры, не озвучивая заново.
3. **Склеить:**
   ```bash
   cd video/tools && swiftc -O render.swift -o build/render && build/render build/scenes.json build/video-only.mp4 ../contentfactory-demo.mp4
   ```
4. **Проверить** (кадры сохранятся рядом с видео):
   ```bash
   swift video/tools/probe.swift video/contentfactory-demo.mp4 12 70 150
   ```

## Курсор и прокрутка

- У сцены в `director.html` есть `timeline` — шаги курсора: `at` (доля длительности сцены), `to` (куда навести), `click` (клик), `state` (какое состояние экрана включить), `drag` (перетаскивание).
- `states` — список действий на странице; каждое состояние снимается отдельным кадром, склейка плавно переключает их в нужный момент.
- `scroll` — прокрутка окна или чата: снимки склеиваются, а меню и колонка чата стоят на месте.
- Сцены одной страницы идут подряд без смены кадра: камера и курсор продолжают с того же места.
- `CF_ONLY=mktBack,mktNext` — снять только эти сцены для проверки.

## Если меняется дизайн

- Изменился текст или порядок сцен — правьте `scenes.py`.
- Изменилась разметка страницы (классы, вкладки) — поправьте селекторы сцены в `director.html`.
- Голос: `CF_VOICE=alena` (или `filipp`) для Яндекса; `say -v Milena` — встроенный. Для живой озвучки — текст с таймкодами в `video/voiceover-script.md`.
